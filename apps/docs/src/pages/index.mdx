## Install

```bash
# macOS (Apple Silicon)
curl -fsSL https://github.com/MaximeGaudin/slint/releases/latest/download/slint-darwin-arm64.tar.gz | sudo tar xz -C /usr/local/bin
```

Prebuilt binaries are published for every release — macOS (Apple Silicon, Intel), Linux (x86_64, arm64), and Windows. Or build from this repo: `cargo install --path apps/cli` (needs Rust 1.95+). Put `~/.cargo/bin` on your `PATH`.

  </div>
  <div>

## Use

```bash
slint                         # every skill under .
slint skills/photo-culling    # or one of them
slint --fix                   # apply computed fixes
slint --format json | jq      # data on stdout
slint rules                   # the catalogue
slint --llm                   # also run model rules
```

  </div>
</div>

Exit codes: `0` clean, `1` errors, `2` warnings only, `3` slint itself failed, `4` nothing was linted (no `SKILL.md` was found under the
given path). Running `slint init` when a config already exists is an idempotent no-op and exits
`0`; nothing is overwritten.

## The model half

Ambiguity, terminology drift, whether a plausible request would actually route here — those need a
reader. One request per skill covers all <ModelRuleCount /> model rules, from OpenAI, Anthropic,
Gemini, Ollama, OpenRouter, Groq, or anything those wire formats reach through a `base_url`.

Nothing is sent until you pass `--llm`, and bundled file contents are never sent — only names and
sizes. [Configure a provider →](/config/)

## Written for people who will disagree with it

Every rule can be turned off, raised, or tuned in `slint.toml`; a document can opt out for itself
with a comment; and the catalogue extends with [plugins](/plugins/) — a data file for the common
case, WebAssembly for the rest.
